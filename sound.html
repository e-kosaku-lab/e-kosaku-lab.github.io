ふみきりと ドレミ

さぼてんきけいに、アンプとスピーカーを足すと、「ふみきり」と「さわってドレミ」が作れます。ふみきりでは、「カンカン」と音が鳴って、画面で、電車（やさぼてんきくん）が通ります。ドレミでは、さわった場所の音が鳴って、さぼてんきくんが、おどります。「お手本モード」で、曲も弾けます。

これは、つぎの一歩です。まず、いつもの「さぼてんきけい」が動いてから、試してね。部品を足して、プログラムを、書き込みなおします。配線は、おうちの人と一緒に、やってください。（書き込むと、いつものプログラムは、いったん消えます。プログラムのページから、もう一度、書き込めば、もどります）

必要な部品（キットのほかに）

部品かずどちらで使う
アンプ MAX98357A（I2S）1ふみきり・ドレミ
小さなスピーカー1ふみきり・ドレミ
赤いLED と、220Ωくらいの抵抗それぞれ 2ふみきり
ワイヤー（さわる場所用）ふみきり 2本、ドレミ 6本ふみきり・ドレミ

ワイヤーのかわりに、アルミホイルや、くだものを、さわる場所に使うことも、できます。

つなぎかた

USBケーブルは、はずしてからね。ワイヤーを、1本ずつ、さします。

画面（OLED）は、いつもの「さぼてんきけい」と同じ4本で、つないだままです。

赤LED（ふみきりだけ）

LEDには、かならず、抵抗をつないでください。抵抗なしでつなぐと、LEDやボードが、こわれることがあります。

さわる場所（ワイヤー）

プログラムESP32のピンはたらき
ふみきりGPIO14（D14）ふみきりが はじまる
ふみきりGPIO27（D27）さぼてんきくんが 通る
ドレミGPIO4・13・14・27・32・33この順に、ド・レ・ミ・ファ・ソ・ラ

ワイヤーの、もう一方の先（金属の部分）は、どこにもつながず、あけておきます。ここを、さわります。くわしくは、タッチ版のページと同じです。

電源が入ったときは、ワイヤーの先に、さわらないでね。（画面に「さわらないでね」と出ている間に、さわっていない時の「ようす」を、おぼえます）

1. ふみきり

ワイヤーを、ちょんとさわると、ふみきりが、はじまります。

  1. 赤いLEDが、かわりばんこに光って、「カン、カン」と鳴る。（画面の警報機も、同じように光る）
  2. しゃだんきが、おりる。
  3. 電車が、通る。たまに、さぼてんきくんや、自分で描いた絵（はじめは、ハート）も、通る。（電車と同じ数だけ、ならんで通ります）
  4. しゃだんきが、あがって、おわり。
  • GPIO14のワイヤー：ふつうに、はじまる。GPIO27のワイヤー：かならず、さぼてんきくんが通る。

かえてみよう

  • CACTUS_PERCENT、ART_PERCENT：さぼてんきくん、自分の絵が通る、わりあい（％）。
  • TRAIN_CARS：電車の車両の数（1〜4）。さぼてんきくんや絵も、この数だけ、ならびます。
  • MY_ART：自分で描いた絵（0と1）。説明書のドット絵メーカーで描いた絵を、貼りつけられます。
  • BELL_HZ_A、BELL_HZ_B：「カン」の高さ。ちがう数字（たとえば 760 と 640）にすると、「カン」「コン」と、かわります。
  • VOLUME：音の大きさ。大きすぎると、ひずみます。耳のために、小さめから、試してね。

// さぼてんきくんの ふみきり（ESP32 + 0.96インチOLED + 赤LED2こ + アンプ・スピーカー）
//
// 「さぼてんきけい」の、追加パックの プログラムです。
// ワイヤーを さわると、ふみきりが「カンカン」と なって、赤いLEDが かわりばんこに 光ります。
// 画面では しゃだんきが おりて、電車が 通ります。たまに、さぼてんきくんや、
// 0と1で かいた 絵（MY_ART）も 通ります。
//
// このプログラムは Wi-Fi / Bluetooth を一切使いません（WiFi.h などを読み込んでいません）。
//
// 必要なライブラリ: U8g2 （olikraus）
// ボード設定: ツール → ボード → esp32 → 「ESP32 Dev Module」
//
// 必要な部品（キットのほかに）:
//   ・赤LED 2こ（それぞれに 220Ω くらいの 抵抗を つなぐ）
//   ・アンプ MAX98357A モジュール（I2S）と、スピーカー
//   ・ワイヤー（さわる場所 用）
//
// 配線:
//   ESP32 3V3     → OLED VDD
//   ESP32 GND     → OLED GND
//   ESP32 GPIO21  → OLED SDA
//   ESP32 GPIO22  → OLED SCK
//   ESP32 GPIO16  → 抵抗 → 赤LED（左）の ＋（足の 長い方）。 LEDの − → GND
//   ESP32 GPIO17  → 抵抗 → 赤LED（右）の ＋（足の 長い方）。 LEDの − → GND
//   ESP32 GPIO26  → アンプ BCLK
//   ESP32 GPIO25  → アンプ LRC
//   ESP32 GPIO18  → アンプ DIN
//   ESP32 5V（VIN）→ アンプ VIN（アンプは、5Vでも 3.3Vでも 動きます）
//   ESP32 GND     → アンプ GND
//   アンプの 出力 → スピーカー（＋と −）
//   ESP32 GPIO14（D14）→ ワイヤー1（さわる場所①）… ふみきりが はじまる
//   ESP32 GPIO27（D27）→ ワイヤー2（さわる場所②）… さぼてんきくんが 通る
//   ワイヤーの、もう一方の先（金属の部分）を、さわります。
//
// つかいかた:
//   ワイヤー1を ちょん → ふみきりが なる → しゃだんきが おりる → 電車（など）が 通る → あがる
//   ワイヤー2を ちょん → ぜったいに さぼてんきくんが 通る
//   ※ 電源を入れる時は、ワイヤーの先に、さわらないでください。

struct TouchPad {
  int pin;
  float base;               // さわっていない時の 値（きじゅん）
  bool down;                // いま さわっているか
  int cnt;                  // ちょうし を みる ための かぞえ
  unsigned long pendMs;     // さわり はじめた とき
  unsigned long downMs;     // さわった ときこく
  bool longFired;
  bool pressedEdge;         // いま さわった
  bool releasedEdge;        // いま はなした
  bool longEdge;            // いま ながく さわった
  unsigned long heldMs;     // はなした とき の、さわっていた 長さ
};

// ESP32 は、さわると 値が 小さくなる
float measureBase(int pin) {
  long sum = 0;
  for (int i = 0; i < 16; i++) {
    sum += touchRead(pin);
    delay(4);
  }
  return sum / 16.0f;
}

void padUpdate(TouchPad &p, unsigned long now) {
  p.pressedEdge = false;
  p.releasedEdge = false;
  p.longEdge = false;
  float v = (float)touchRead(p.pin);
  bool raw = v < p.base * TOUCH_RATIO;
  if (raw == p.down) {
    p.cnt = 0;
    // さわっていない間は、きじゅんを、ゆっくり なおす
    if (!raw && v > p.base * 0.8f) p.base = p.base * 0.98f + v * 0.02f;
  } else {
    if (p.cnt == 0) p.pendMs = now;
    p.cnt++;
    if (p.cnt >= TOUCH_CONFIRM) {  // 3回つづけて 同じ → きまり（ちらつき よけ。かず は TOUCH_CONFIRM）
      p.down = raw;
      p.cnt = 0;
      if (raw) {
        p.pressedEdge = true;
        p.downMs = p.pendMs;
        p.longFired = false;
      } else {
        p.releasedEdge = true;
        p.heldMs = now - p.downMs;
      }
    }
  }
  if (p.down && !p.longFired && now - p.downMs >= LONG_MS) {
    p.longFired = true;
    p.longEdge = true;
  }
}

// ---- 音を出す（MAX98357A アンプ + スピーカー）----
// 音は、「音のたんとう」の仕事（別の仕事）が、ずっと出しつづけます。
// g_freq に、音の高さ（Hz）を入れると、その音が鳴りつづけます。0 を入れると、しずかになります。
// g_bellHz に、音の高さ（Hz）を入れると、かねを「カーン」と 1回 たたいた音が 鳴ります（すぐ 0 にもどります）。
const int SAMPLE_RATE = 16000;
I2SClass i2s;
volatile int g_freq = 0;
volatile int g_bellHz = 0;

void audioTask(void *arg) {
  static int16_t buf[160];
  float phase = 0, amp = 0;
  float bellPhase = 0, bellStep = 0, bellAmp = 0;
  while (true) {
    int bh = g_bellHz;
    if (bh > 0) {                 // かねを たたく
      bellStep = 2.0f * 3.14159265f * bh / SAMPLE_RATE;
      bellPhase = 0;
      bellAmp = 1.0f;
      g_bellHz = 0;
    }
    int f = g_freq;
    float target = (f > 0) ? (float)VOLUME : 0.0f;
    float step = (f > 0) ? (2.0f * 3.14159265f * f / SAMPLE_RATE) : 0.0f;
    for (int i = 0; i < 160; i++) {
      amp += (target - amp) * 0.02f;   // ふわっと 大きく・小さく（ぶつっ という音を へらす）
      phase += step;
      if (phase > 6.2831853f) phase -= 6.2831853f;
      float v = (sinf(phase) + 0.3f * sinf(phase * 3.0f)) * amp * 0.75f;
      if (bellAmp > 0.001f) {       // かねの 音: 高い 音が まざって、だんだん 小さくなる
        bellPhase += bellStep;
        float b = sinf(bellPhase) + 0.5f * sinf(bellPhase * 2.76f) + 0.25f * sinf(bellPhase * 5.4f);
        v += b * bellAmp * VOLUME * 0.5f;
        bellAmp *= 0.9993f;         // 「カーン」の 長さ（1に ちかいほど 長い）
      }
      buf[i] = (int16_t)v;
    }
    i2s.write((uint8_t *)buf, sizeof(buf));
  }
}

void audioBegin() {
  i2s.setPins(I2S_BCLK, I2S_LRC, I2S_DIN);
  if (!i2s.begin(I2S_MODE_STD, SAMPLE_RATE, I2S_DATA_BIT_WIDTH_16BIT, I2S_SLOT_MODE_MONO)) {
    Serial.println("アンプ（MAX98357A）が はじめられません。配線を たしかめてください");
    return;
  }
  xTaskCreatePinnedToCore(audioTask, "audio", 4096, NULL, 1, NULL, 0);
}

const int ARM_UP_DEG = 60;     // あがっている ときの かくど（90 で まっすぐ 上）
const int ARM_DOWN_DEG = 2;    // おりている ときの かくど（0 で よこ）

// しゃだんき（あかと しろの しま もよう）
void drawArm(int px, int dir, float up) {
  // up: 1 = あがっている、0 = おりている
  float deg = ARM_DOWN_DEG + up * (ARM_UP_DEG - ARM_DOWN_DEG);
  float rad = deg * 3.14159265f / 180.0f;
  float dx = dir * cosf(rad);
  float dy = -sinf(rad);
  int n = ARM_LEN / 6;
  for (int k = 0; k < n; k++) {
    int x0 = px + (int)(dx * k * 6);
    int y0 = PIVOT_Y + (int)(dy * k * 6);
    int x1 = px + (int)(dx * (k + 1) * 6);
    int y1 = PIVOT_Y + (int)(dy * (k + 1) * 6);
    display.drawLine(x0, y0, x1, y1);
    if (k % 2 == 0) {                       // ふとい ところ（赤）
      display.drawLine(x0, y0 + 1, x1, y1 + 1);
      display.drawLine(x0, y0 + 2, x1, y1 + 2);
    }
  }
}

// ---- 画面の そとへ はみだしても だいじょうぶな かきかた ----
// U8g2 は、画面の 左の そと（x が マイナス）に はみだす 絵を かくと、反対がわ（右がわ）に
// へんな 線が 出ることが あります。そこで、はみだす ぶんは、自分で けずって から かきます。
void cPixel(int x, int y) {
  if (x >= 0 && x < 128 && y >= 0 && y < 64) display.drawPixel(x, y);
}
void cHLine(int x, int y, int w) {
  if (x < 0) { w += x; x = 0; }
  if (x + w > 128) w = 128 - x;
  if (w > 0 && y >= 0 && y < 64) display.drawHLine(x, y, w);
}
void cVLine(int x, int y, int h) {
  if (y < 0) { h += y; y = 0; }
  if (y + h > 64) h = 64 - y;
  if (h > 0 && x >= 0 && x < 128) display.drawVLine(x, y, h);
}
void cBox(int x, int y, int w, int h) {
  if (x < 0) { w += x; x = 0; }
  if (y < 0) { h += y; y = 0; }
  if (x + w > 128) w = 128 - x;
  if (y + h > 64) h = 64 - y;
  if (w > 0 && h > 0) display.drawBox(x, y, w, h);
}
void cLine(int x0, int y0, int x1, int y1) {
  int dx = abs(x1 - x0), dy = abs(y1 - y0);
  int sx = (x0 < x1) ? 1 : -1, sy = (y0 < y1) ? 1 : -1;
  int err = dx - dy;
  while (true) {
    cPixel(x0, y0);
    if (x0 == x1 && y0 == y1) break;
    int e2 = 2 * err;
    if (e2 > -dy) { err -= dy; x0 += sx; }
    if (e2 < dx) { err += dx; y0 += sy; }
  }
}
void cDisc(int cx, int cy, int r) {
  for (int dy = -r; dy <= r; dy++)
    for (int dx = -r; dx <= r; dx++)
      if (dx * dx + dy * dy <= r * r) cPixel(cx + dx, cy + dy);
}
void cRFrame(int x, int y, int w, int h) {   // かどの まるい わく
  cHLine(x + 2, y, w - 4);
  cHLine(x + 2, y + h - 1, w - 4);
  cVLine(x, y + 2, h - 4);
  cVLine(x + w - 1, y + 2, h - 4);
  cPixel(x + 1, y + 1); cPixel(x + w - 2, y + 1);
  cPixel(x + 1, y + h - 2); cPixel(x + w - 2, y + h - 2);
}
void cMark(const char *const mark[], int x, int y, int scale) {   // 0と1の絵（はみだしても OK）
  for (int row = 0; row < MARK_SIZE; row++) {
    const char *line = mark[row];
    for (int col = 0; col < MARK_SIZE && line[col] != '\0'; col++) {
      if (line[col] == '1') cBox(x + col * scale, y + row * scale, scale, scale);
    }
  }
}

void startCrossing(unsigned long now, bool forceCactus) {
  st = ST_PRE;
  stMs = now;
  lampPhase = -1;
  alarmStart = now;
  int r = random(0, 100);
  if (forceCactus || r < CACTUS_PERCENT) kind = K_CACTUS;
  else if (r < CACTUS_PERCENT + ART_PERCENT) kind = K_ART;
  else kind = K_TRAIN;
  passX = (kind == K_TRAIN) ? -30.0f : -32.0f;   // 画面の 左の そとから はじめる
  lastPassMs = now;
}

  pad2.base = measureBase(pad2.pin);
  Serial.printf("タッチの きじゅん 1=%.0f 2=%.0f\n", pad1.base, pad2.base);
  randomSeed(esp_random() ^ micros());

void loop() {
  unsigned long now = millis();
  padUpdate(pad1, now);
  padUpdate(pad2, now);

  if (st == ST_IDLE) {
    if (pad1.pressedEdge) startCrossing(now, false);
    else if (pad2.pressedEdge) startCrossing(now, true);
  } else if (st == ST_PRE) {
    if (now - stMs >= PRE_MS) { st = ST_LOWER; stMs = now; }
  } else if (st == ST_LOWER) {
    if (now - stMs >= LOWER_MS) { st = ST_PASS; stMs = now; lastPassMs = now; }
  } else if (st == ST_PASS) {
    float speed = (kind == K_TRAIN) ? TRAIN_SPEED : WALK_SPEED;
    passX += speed * (now - lastPassMs) / 1000.0f;
    lastPassMs = now;
    if (passX - tailLen() > 128) { st = ST_RAISE; stMs = now; }   // うしろまで 画面の そとに 出たら おわり
  } else if (st == ST_RAISE) {
    if (now - stMs >= RAISE_MS) { st = ST_IDLE; stMs = now; }
  }

  // ---- LED と 音（なっている間だけ）----
  if (st == ST_IDLE) {
    digitalWrite(LED_L, LOW);
    digitalWrite(LED_R, LOW);
    lampPhase = -1;
  } else {
    int phase = ((now - alarmStart) / LAMP_MS) % 2;   // かわりばんこ
    if (phase != lampPhase) {      // 光る ほうが かわった しゅんかんに「カン」と たたく
      lampPhase = phase;
      digitalWrite(LED_L, phase == 0 ? HIGH : LOW);
      digitalWrite(LED_R, phase == 1 ? HIGH : LOW);
      g_bellHz = (phase == 0) ? BELL_HZ_A : BELL_HZ_B;   // かねを たたく（カーン）
    }
  }

  drawScene(now);
}

2. さわって ドレミ

ワイヤーを、さわると、その音が鳴ります。さぼてんきくんは、音の場所へ行って、おどります。

  • 2本いっしょにさわったときは、あとからさわったほうの音が、鳴ります。
  • ふつうの音階は、ド・レ・ミ・ファ・ソ・ラ の6つです。

お手本モード（曲が弾けます）

  1. 「ド」のワイヤーを、2秒さわりつづける。「お手本モード」になります。
  2. 画面に、曲の名前と、▼の印が出ます。▼が出ている鍵盤を、さわります。
  3. じゅんばんにさわると、曲が弾けます。さいごまで弾くと、「できた!」と出て、さぼてんきくんが、喜びます。
  4. 違う鍵盤をさわると、さぼてんきくんが、「いたい!」の顔になります。（その音は鳴ります）
  5. もう一度、「ド」を2秒さわると、つぎの曲になります。

曲は、「めりーさんの ひつじ」「きらきらぼし」「ちょうちょう」の3つです。同じ音がつづくところは、1回ずつ、ワイヤーから指をはなして、さわり直します。

かえてみよう

  • NOTE_HZ：音の高さ（Hz）。数字が大きいほど、高い音です。
  • SONG_MARY など：曲の音の並び。ド=0、レ=1、ミ=2、ファ=3、ソ=4、ラ=5の数字を、じゅんばんに書くと、自分の曲が作れます。
  • VOLUME：音の大きさ。

struct TouchPad {
  int pin;
  float base;               // さわっていない時の 値（きじゅん）
  bool down;                // いま さわっているか
  int cnt;                  // ちょうし を みる ための かぞえ
  unsigned long pendMs;     // さわり はじめた とき
  unsigned long downMs;     // さわった ときこく
  bool longFired;
  bool pressedEdge;         // いま さわった
  bool releasedEdge;        // いま はなした
  bool longEdge;            // いま ながく さわった
  unsigned long heldMs;     // はなした とき の、さわっていた 長さ
};

// ESP32 は、さわると 値が 小さくなる
float measureBase(int pin) {
  long sum = 0;
  for (int i = 0; i < 16; i++) {
    sum += touchRead(pin);
    delay(4);
  }
  return sum / 16.0f;
}

void padUpdate(TouchPad &p, unsigned long now) {
  p.pressedEdge = false;
  p.releasedEdge = false;
  p.longEdge = false;
  float v = (float)touchRead(p.pin);
  bool raw = v < p.base * TOUCH_RATIO;
  if (raw == p.down) {
    p.cnt = 0;
    // さわっていない間は、きじゅんを、ゆっくり なおす
    if (!raw && v > p.base * 0.8f) p.base = p.base * 0.98f + v * 0.02f;
  } else {
    if (p.cnt == 0) p.pendMs = now;
    p.cnt++;
    if (p.cnt >= TOUCH_CONFIRM) {  // 3回つづけて 同じ → きまり（ちらつき よけ。かず は TOUCH_CONFIRM）
      p.down = raw;
      p.cnt = 0;
      if (raw) {
        p.pressedEdge = true;
        p.downMs = p.pendMs;
        p.longFired = false;
      } else {
        p.releasedEdge = true;
        p.heldMs = now - p.downMs;
      }
    }
  }
  if (p.down && !p.longFired && now - p.downMs >= LONG_MS) {
    p.longFired = true;
    p.longEdge = true;
  }
}

// ---- 音を出す（MAX98357A アンプ + スピーカー）----
// 音は、「音のたんとう」の仕事（別の仕事）が、ずっと出しつづけます。
// g_freq に、音の高さ（Hz）を入れると、その音が鳴りつづけます。0 を入れると、しずかになります。
// g_bellHz に、音の高さ（Hz）を入れると、かねを「カーン」と 1回 たたいた音が 鳴ります（すぐ 0 にもどります）。
const int SAMPLE_RATE = 16000;
I2SClass i2s;
volatile int g_freq = 0;
volatile int g_bellHz = 0;

void audioTask(void *arg) {
  static int16_t buf[160];
  float phase = 0, amp = 0;
  float bellPhase = 0, bellStep = 0, bellAmp = 0;
  while (true) {
    int bh = g_bellHz;
    if (bh > 0) {                 // かねを たたく
      bellStep = 2.0f * 3.14159265f * bh / SAMPLE_RATE;
      bellPhase = 0;
      bellAmp = 1.0f;
      g_bellHz = 0;
    }
    int f = g_freq;
    float target = (f > 0) ? (float)VOLUME : 0.0f;
    float step = (f > 0) ? (2.0f * 3.14159265f * f / SAMPLE_RATE) : 0.0f;
    for (int i = 0; i < 160; i++) {
      amp += (target - amp) * 0.02f;   // ふわっと 大きく・小さく（ぶつっ という音を へらす）
      phase += step;
      if (phase > 6.2831853f) phase -= 6.2831853f;
      float v = (sinf(phase) + 0.3f * sinf(phase * 3.0f)) * amp * 0.75f;
      if (bellAmp > 0.001f) {       // かねの 音: 高い 音が まざって、だんだん 小さくなる
        bellPhase += bellStep;
        float b = sinf(bellPhase) + 0.5f * sinf(bellPhase * 2.76f) + 0.25f * sinf(bellPhase * 5.4f);
        v += b * bellAmp * VOLUME * 0.5f;
        bellAmp *= 0.9993f;         // 「カーン」の 長さ（1に ちかいほど 長い）
      }
      buf[i] = (int16_t)v;
    }
    i2s.write((uint8_t *)buf, sizeof(buf));
  }
}

void audioBegin() {
  i2s.setPins(I2S_BCLK, I2S_LRC, I2S_DIN);
  if (!i2s.begin(I2S_MODE_STD, SAMPLE_RATE, I2S_DATA_BIT_WIDTH_16BIT, I2S_SLOT_MODE_MONO)) {
    Serial.println("アンプ（MAX98357A）が はじめられません。配線を たしかめてください");
    return;
  }
  xTaskCreatePinnedToCore(audioTask, "audio", 4096, NULL, 1, NULL, 0);
}

void drawScene(unsigned long now) {
  display.clearBuffer();
  display.setFont(u8g2_font_b12_t_japanese2);
  bool teach = (songMode >= 0);

  // さぼてんきくん
  const char *const *m;
  int hop = 0;
  bool dance = (current >= 0) || songDone;
  int f = (now / DANCE_MS) % 2;
  if (teach && now < missUntil) {
    m = f ? MARK_ITAI2 : MARK_ITAI;
  } else if (dance) {
    hop = f ? -5 : 0;
    m = f ? MARK_TERE2 : MARK_KAITEKI2;
    if (current >= 3 || songDone) m = f ? MARK_TERE : MARK_TERE2;
  } else {
    m = ((now / ANIME_MS) % 2) ? MARK_KAITEKI2 : MARK_KAITEKI;
  }
  int cy = teach ? 6 : 11;
  drawMarkS(m, (int)cactusX, cy + (hop < 0 ? hop : 0), MARK_SCALE);

  // お手本の 表示
  if (teach) {
    char t[24];
    display.drawUTF8(0, 13, SONGS[songMode].name);
    if (songDone) snprintf(t, sizeof(t), "できた!");
    else snprintf(t, sizeof(t), "%d/%d", songPos + 1, SONGS[songMode].n);
    display.drawUTF8(0, 29, t);
    if (!songDone && (now / 300) % 2 == 0) {
      int tn = SONGS[songMode].notes[songPos];
      int cx = KEY_X0 + tn * (KEY_W + 1) + KEY_W / 2;
      display.drawTriangle(cx - 4, 40, cx + 4, 40, cx, 46);   // つぎは ここ！
    }
  }

  // 鍵盤
  display.setFont(u8g2_font_b10_t_japanese1);
  for (int i = 0; i < NPADS; i++) {
    int x = KEY_X0 + i * (KEY_W + 1);
    bool on = (i == current);
    if (on) display.drawBox(x, KEY_Y, KEY_W, 16);
    else display.drawFrame(x, KEY_Y, KEY_W, 16);
    display.setDrawColor(on ? 0 : 1);
    int w = display.getUTF8Width(NOTE_NAME[i]);
    display.drawUTF8(x + (KEY_W - w) / 2, KEY_Y + 12, NOTE_NAME[i]);
    display.setDrawColor(1);
  }
  display.sendBuffer();
}

void loop() {
  unsigned long now = millis();
  for (int i = 0; i < NPADS; i++) {
    padUpdate(pads[i], now);
    if (pads[i].pressedEdge) lastPress[i] = now;
  }

  // 「ド」を 2びょう さわりつづけると、お手本モードを きりかえる
  if (pads[0].pressedEdge) modeFired = false;
  if (pads[0].down && !modeFired && now - pads[0].downMs >= MODE_HOLD_MS) {
    modeFired = true;
    songMode++;
    if (songMode >= SONG_N) songMode = -1;
    songPos = 0;
    songDone = false;
    Serial.printf("お手本モード = %d\n", songMode);
  }

  // さわっている 中で、いちばん あとから さわった ものの 音を 鳴らす
  // （モードを きりかえている 間の「ド」は、しずかに する）
  int best = -1;
  for (int i = 0; i < NPADS; i++) {
    if (!pads[i].down) continue;
    if (i == 0 && modeFired) continue;
    if (best < 0 || lastPress[i] > lastPress[best]) best = i;
  }
  current = best;
  g_freq = (best >= 0) ? NOTE_HZ[best] : 0;

  // お手本: つぎの 音を さわったら すすむ
  if (songMode >= 0) {
    if (songDone) {
      if (now - doneMs > 3000) { songDone = false; songPos = 0; }   // 3びょう あと、さいしょから
    } else {
      for (int i = 0; i < NPADS; i++) {
        if (!pads[i].pressedEdge || (i == 0 && modeFired)) continue;
        if (i == SONGS[songMode].notes[songPos]) {
          songPos++;
          if (songPos >= SONGS[songMode].n) { songDone = true; doneMs = now; }
        } else {
          missUntil = now + 400;      // ちがう 音
        }
      }
    }
  }

  // さぼてんきくんは、音の 場所へ（お手本モードでは 右がわに いる）
  float target = cactusX;
  if (songMode >= 0) {
    target = 92;
  } else if (current >= 0) {
    target = KEY_X0 + current * (KEY_W + 1) + KEY_W / 2 - MARK_SIZE * MARK_SCALE / 2;
  }
  if (target < 0) target = 0;
  if (target > 128 - MARK_SIZE * MARK_SCALE) target = 128 - MARK_SIZE * MARK_SCALE;
  cactusX += (target - cactusX) * 0.35f;

  drawScene(now);
}

書き込みのやりかた

  1. Arduino IDE で、「ファイル」→「新規スケッチ」を選び、はじめから書いてある文字を、ぜんぶ消す。
  2. 上の「…をコピーする」を押して、貼りつける。
  3. ボードとポートを選んで、→（書き込み）ボタンを押す。（くわしくは、書き込みのやりかた）名前は「fumikiri」「doremi」などで、保存する。

うまくいかないとき

  • 音が出ない：アンプの配線（BCLK・LRC・DIN・VIN・GND）と、スピーカーの＋−を、たしかめます。VOLUMEの数字を、大きくしてみます。シリアルモニター（115200）に「アンプが はじめられません」と出ていないかも、見ます。
  • 音がひずむ：VOLUMEの数字を、小さくします。
  • LEDが光らない：LEDの向き（足の長い方が＋）と、抵抗を、たしかめます。
  • さわっても反応しない・反応しすぎる：プログラムの先頭の TOUCH_RATIO の数字を、かえてみます。反応しすぎる時は 小さく、反応しない時は 大きく（0.3〜0.9の間）。
