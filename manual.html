さぼてんきけい 説明書

温度・湿度・気圧を、小さな画面に出します。はんだ付けはいりません。おうちの人といっしょに、ゆっくり進めてください。

おうちの人へ：パソコンの準備、AIの使いかた、うまくいかないときの直しかたは、おうちの人へのページにまとめました。先に一度、目を通してください。

4つのステップで進めます

ステップすることパソコン目安
1. 光った！ワイヤーをつないで、USBをさす。画面に温度が出る電気をもらうだけ30分〜1時間
2. 変えてみよう数字 → 言葉 → 0と1の絵 を、じぶんで書きかえるおうちの人が準備1〜2時間
3. AIにお願い「こうしたい」を考えて、おうちの人がAIにたのむ。画面でたしかめるおうちの人が操作30分〜
4. じぶんで考える新しい表示や遊びを考えて、作ってみるいっしょにすきなだけ

1日で全部やらなくてだいじょうぶです。ステップ1だけで、その日はおしまいでもOKです。

はじめに（おうちの人といっしょに読んでね）

電波法・技適について

キットのESP32ボードには、技適マークがありません。付属のプログラムは、Wi-Fi・Bluetoothを使いません。日本国内で、技適のないボードのWi-Fi・Bluetoothを使うと、電波法違反になるおそれがあります。無線を使うプログラムを書くときは、ご自身で法令を確認してください。

  • 対象年齢の目安は、小学3年生以上です。おうちの人といっしょにお使いください。
  • 小さな部品があります。小さなお子さまが口に入れないよう、気をつけてください。
  • 使う電気は、USBからの小さな電気だけです。家のコンセントに直接つなぐ部品はありません。
  • AIは、おうちの人が操作してください。AIのサービスには、使える年齢の条件があります（おうちの人へ「AIを使うとき」）。
  • 動作確認は出荷前に行っていますが、市販品のような保証・修理はできません。

1-2. 部品をさす（配線）

USBケーブルは、まだささないでね。電気が来ていない状態で作ります。

画面とセンサーは、同じ4本のワイヤーを、2つで分け合ってつなぎます。（ワイヤー ＝ ジャンパーワイヤー。部品どうしをつなぐ、細い電線のことです）

はたらきESP32のピン画面（OLED）センサー
電気（＋）3V3（3.3V）VDDVDD
電気（−）GNDGNDGND
データD21（GPIO21）SDASDA
時計D22（GPIO22）SCKSCL
気をつけること
  • 電気（＋）のワイヤーは、かならず「3V3」につなぎます。「5V」「VIN」には、つなぎません（ESP32ボードのピンのことです）。
  • 「3V3」は、3.3ボルト（V）の電気が出るピンです。「5V」は5ボルトで、部品によっては、こわれてしまうことがあります。
  • ワイヤーの色は、どれでもだいじょうぶです。同じはたらきのワイヤーは、同じ色にそろえると、まちがえにくくなります。
  • 画面とセンサーは、足のならび順がちがいます（下の写真）。基板に書いてある名前（VDD・GND・SDA・SCL）を見て、つなぎます。虫めがねがあると見やすいよ。
  • ESP32のピンは、左右に分かれています。ボードに書いてある名前（3V3・GND・D21・D22）をさがします。

部品の足の名前が、ちがうとき

部品によって、同じはたらきの足に、ちがう名前がついていることがあります。よく見る名前は、こうです。

はたらきこの説明書の名前ほかによくある名前
電気（＋）VDDVCC、VIN、3V3
電気（−）GNDVSS
データSDASDI
時計SCLSCK
  • 迷ったら、部品の商品ページや、基板の説明で、はたらきを確かめよう。
  • 部品についている「VIN」は、電気（＋）の入り口です。ESP32ボードの「VIN」は、別のもの（5Vの電気）なので、つながないでね。

足の名前を、写真で見くらべよう

画面とセンサーは、足の名前も、ならび順も、ちがいます。ならび順で覚えず、書いてある名前を見て、つなぎます。

画面の保護フィルム：画面には、うすい保護フィルムが、ついています。青いラベルの部分をつまんで、はがしてから、使います。

センサーは、表と裏を、見くらべてみよう。

ESP32ボードのピンの名前も、ボードの両はしに書いてあります（3V3・GND・D21・D22をさがします）。

ブレッドボードの中のようす

ブレッドボードは、穴の下で、金属の板が穴どうしをつないでいます。見えないけれど、こんなふうにつながっています。

  • たて5つの穴は、つながっています。同じ列にさしたものは、電気がつながります。
  • まん中のみぞの上と下は、つながっていません。ESP32のように足が2列あるボードは、みぞをまたいでさします。こうすると、左右の足が、べつべつの列になります。
  • ふちの長い列は、横にずっとつながっています。電気（＋）や電気（−）を、みんなで使うときに便利です。
  • ワイヤーは、はなれた列どうしをつなぐために使います。

ブレッドボードにさす

  1. ESP32ボードを、ブレッドボードの真ん中のみぞをまたぐようにさす。（ボードが大きいので、さしたあとに使える穴は、ボードの外がわの列だけになります）
  2. 画面とセンサーを、ブレッドボードのあいている場所にさす。
  3. 上の表のとおりに、ワイヤーでつなぐ。

ブレッドボードの穴の位置で見る配線

ブレッドボードには、列の番号（1〜30）と、行の文字（a〜j）が書いてあります。下の図は、ESP32 をUSBが「1」の側（右）になる向きにさして、画面とセンサーを左はしにさしたときの、ワイヤーのつなぎかたです。

色つなぐ穴（列の番号＋行の文字）はたらき
赤19j（ESP32の「3V3」）→ 28c（センサーの VDD の列）電気（＋）をセンサーへ
オレンジ28d（センサーの VDD の列）→ 27h（画面の VDD の列）電気（＋）を画面へ
黒19a（ESP32の「GND」）→ 26c（センサーの GND の列）電気（−）をセンサーへ
灰色26d（センサーの GND の列）→ 28h（画面の GND の列）電気（−）を画面へ
黄14a（ESP32の「D21」）→ 27c（センサーの SDA の列）データをセンサーへ
白27d（センサーの SDA の列）→ 25h（画面の SDA の列）データを画面へ
緑17a（ESP32の「D22」）→ 25c（センサーの SCL の列）時計をセンサーへ
紫25d（センサーの SCL の列）→ 26h（画面の SCK の列）時計を画面へ
  • 「19j」は、「19列の、jの行の穴」のことです。ESP32の足が入っている行（b と i）の、すぐ外がわの穴（a と j）を使います。
  • センサーの足は、a の行の 28〜25 列に、画面の足は、j の行の 28〜25 列にさします。センサーの足は左から VDD・SDA・GND・SCL、画面の足は左から GND・VDD・SCK・SDA の順です。
  • 同じ列の a〜e の穴は、つながっています（f〜j も同じ）。そのため、センサーの足の列の c・d の穴を使えます。

写真で、順番に見よう

ワイヤーのさしかた：1本ずつ、「どこから、どこへ」を、指でしっかり指して、たしかめます。ワイヤーをさすまで、指さしを続けましょう。さしたあとは、ぐらぐらしないか、見てください。

できあがり

さす前に、指さしチェック

  • 電気（＋）のワイヤーが「3V3」、電気（−）のワイヤーが「GND」
  • 「D21」は SDA、「D22」は SCL
  • 画面にも、センサーにも、4つの足（VDD・GND・SDA・SCL）のワイヤーがつながっている

1-3. USBをさす

  1. USBケーブルで、ボードとパソコンをつなぐ。（パソコンは、電気をもらうためだけに使います。まだ何もしなくてOK）スマホ用のUSB充電器や、モバイルバッテリーでも、動きます。
  2. 2秒くらい「さぼてんきけい」の画面が出て、そのあと、こんなふうに出たらせいこう！
温度 24.5 C
湿度 52%
気圧 1013 hPa
かいてき

たしかめてみよう

  • センサーに「はーっ」と息をふきかけると、湿度の数字が上がるかな？
  • 湿度が70%以上になると「じめじめ」、40%より低いと「からから」と出て、右上のさぼてんきくん（サボテンのキャラクター）の顔もかわります。
  • さぼてんきくんが、ゆらゆら動いて見えるかな？ 絵が2まいあって、半秒ごとに切りかわっています。
  • 気圧の数字は、下の「気圧の数字のみかた」で見てみよう。毎日見てみよう。

動画で見てみよう

  • からから湿度 40%より低い
  • かいてき湿度 40〜70%
  • じめじめ湿度 70%以上

気圧の数字のみかた

気圧は「hPa（ヘクトパスカル）」という単位です。

数字（目安）ようす
1020 より上高気圧。晴れやすい
1013 くらいふつう（標準の気圧）
1000 より下低気圧。くもりや雨になりやすい
  • 数字そのものより、数時間のあいだの変わりかたが大事です。ぐんぐん下がっていくとき（目安：3時間で3hPa以上）は、天気がくずれやすくなります。
  • キットの気圧は、今いる場所の高さの気圧です。高い所ほど低く出ます（100mで約12hPa）。天気予報の気圧は、海面の高さにそろえた数字なので、ちがう数字になることがあります。まず数日、じぶんの家の「ふだんの数字」を見つけよう。

うまくいかないときは

うまくいかないのは、ふつうのことです。どこがちがうか、1つずつさがすのが電子工作のたのしいところです。

画面に何も出ない
  1. 画面の VDD が 3V3、GND が GND につながっているか。
  2. SDA が D21、SCL が D22 か（入れかわっていないか）。
  3. ワイヤーがしっかりささっているか。ゆるいときは、予備のワイヤーにかえる。
「センサーが つながって いません」と出る
  1. センサーの4つの足（VDD・GND・SDA・SCL）のワイヤーをたしかめる。
  2. 予備のワイヤーにかえてみる。
気圧が「---」になる

センサーのワイヤーをたしかめる。それでもだめなら、おうちの人へ「うまくいかないとき」へ。

ボードの明かり（LED）もつかない

USBケーブルをさしなおす。パソコンの別の差し込み口にさしてみる。

2変えてみよう

ここからは、パソコンでプログラムを書きかえます。パソコンの準備は、おうちの人にお願いしてね。（おうちの人へ「パソコンの準備」）

2-0. プログラムを開く

  1. プログラム sabotenkikei.ino を開く。
    プログラムのページ（GitHub）
  2. いちばん上のほうに、かえてみよう！ と書いてあるところがあるよ。そこから かえてみよう ここまで までが、きみが書きかえていい場所です。
  3. 書きかえたら、→（書き込み）ボタンをおすと、ボードに送られます。
まちがえても、こわれません。わからなくなったら、プログラムを開きなおせば、元にもどります。

2-1. 数字をかえてみよう

const float JIMEJIME_LINE = 70;  // これ以上で じめじめ
  • 70 を 50 にして書き込んでみよう。どうなるかな？
  • 息をふきかけて、マークがかわるのをたしかめよう。
  • ためしたら、ノートに書いておこう。「50にしたら、すぐ じめじめ になった」など。

れい：「からから」の数字を、40 から 50 にかえると、湿度45%でも「からから」と出るようになります。

動くはやさもかえられるよ

さぼてんきくんは、2まいの絵がこうたいに出て、動いているように見えます。その切りかえの間かくも、かえられます。

const unsigned long ANIME_MS = 500;  // 絵をきりかえる間かく（1000 = 1秒）
  • 500 を 200 にすると、はやく動きます。1000 にすると、ゆっくりです。
  • 50 より小さくしないでね。

2-2. 言葉をかえてみよう

const char *WORD_KAITEKI  = "かいてき";
  • " " の中を、すきな言葉にかえてみよう。たとえば "いいかんじ" "ごきげん"。
  • " はけさないでね。けすと、書き込みのときに赤い文字が出ます（そのときは " をもどせばOK）。
  • むずかしい漢字は、画面に出ないことがあります。ひらがな・カタカナがおすすめ。

2-3. 0と1で、絵をかえてみよう

マークの絵は、0 と 1 でできています。1 が光るドット、0 が光らないドットです。1行に16こ、16行あります。

// かいてき: にこにこ顔の さぼてんきくん
const char *MARK_KAITEKI[16] = {
  "0000000110000000",
  "0000001111000000",
  …

絵は、1つの顔につき2まいあります。名前のさいごに 2 がついているのが、絵2です（MARK_KAITEKI が絵1、MARK_KAITEKI2 が絵2）。2まいをこうたいに出すので、動いて見えます。絵2は、絵1と、ちがうところが少しだけあります。どこがちがうか、さがしてみよう。

ドット絵メーカー

マスをタッチ（クリック）すると、ぬったり消したりできます。なぞると続けてぬれます。下に、0と1が出てきます。

紙でもできるよ：方眼紙に、たて16マス・よこ16マスをかいて、えんぴつでぬる。ぬったマスは 1、ぬっていないマスは 0。1行ずつ、左から順番に書きうつします。

コツ

  • 1行は、かならず16こ。数えまちがえると、絵がずれます。ずれたら、どの行がちがうか、さがしてみよう。
  • " と ,（カンマ）は、けさないでね。
  • 画面では、1ドットが2倍の大きさで出ます。

3AIにお願い

「こうしたい！」をきみが考えて、おうちの人がAIにたのみます。AIのこたえが本当に正しいかは、画面に書き込んで、きみがたしかめます。

AIの使いかたのルールは、おうちの人へ「AIを使うとき」を見てください。

3-1. たのむ言葉を考えよう

AIには、何を・どうしたいかを、くわしく言うほど伝わります。

あまり伝わらないよく伝わる
「かわいくして」「さぼてんきくんの目を、ハートの形にして」
「あつい時も出して」「温度が28度以上のときは『あつい』と出して、太陽のマークを出して」
「もっと動かして」「さぼてんきくんの絵を、2倍はやく切りかえて」

たのむときは、プログラムぜんぶをいっしょにわたして、さいごにこう書きます。

このプログラムは、ESP32と0.96インチのOLED（U8g2）で、温度と湿度を表示するものです。
「（ここに、やりたいこと）」ように変えてください。
変えたところがわかるように、変えた行にコメントを書いてください。

3-2. たしかめよう

  1. AIがかえたプログラムを書き込む。
  2. 画面を見て、たのんだとおりになっているかたしかめる。温度の話なら、センサーを手でにぎって温めてみる。湿度の話なら、息をふきかけてみる。
  3. ちがっていたら、何がちがったかをそのままAIに伝える。
    例：「ハートが出ません。画面には何も出なくなりました」
    例：「『あつい』の字が出ません。四角い記号になります」

ほんとうにあった話：このキットを作るときも、AIが書いたプログラムで日本語が出ないことがありました。人が調べて、たしかめて、直しました。

AIはまちがえることがあります。たしかめるのは、きみの目です。

4じぶんで考える

ここまでできたら、もう「作る人」です。じぶんのアイデアで作ってみよう。

4-1. アイデアシート

紙に書いてみよう。

  • 画面に、何を出したい？
  • それは、どんなときに出る？（あつい時？ 夜？ 1分ごと？）
  • どんな絵にする？（16×16マスにかいてみよう）
  • 名前をつけるなら？

4-2. アイデアのヒント

  • あつい・さむいも出す（温度で、マークをかえる）
  • じぶんのキャラクターを考えて、かいてき・じめじめ・からからの3つの顔をかく（さぼてんきくんのように）
  • 気圧のマーク（気圧が低い日は、かさのマーク）
  • もっと動かす（絵を3まいにふやして、順番に出す。AIに手つだってもらおう）

作りかたは、ステップ2（じぶんで書きかえる）と、ステップ3（AIにたのむ）の組み合わせです。うまくいかなかったら、小さく分けて、1つずつたしかめよう。できたら、写真をとっておこう。

できた！ もっとやりたくなったら、つぎは何をしようかな。
